# HTTP route/source inventory — v1.0.0

Paths below are registration strings relative to their Gin router group, **not complete URLs**. Prefix the configured web base path and the relevant group. The API group is `/panel/api` (inbounds, clients, server, custom-geo); authenticated browser management is `/panel` (nodes, core, setting, xray, admins, resellers and groups). Node agent enrollment/sync is registered separately under `/node-agent`; subscription routes use their configured subscription path. Authentication, two-factor, role and object-scope middleware remain mandatory.

See the [API reference](../api-reference.md) for payloads, encoding, error envelopes and examples. This source inventory does not grant permissions or imply identical request binders.
