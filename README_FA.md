# VPN-UI — نسخهٔ admin6501

[English](README.md) | [فارسی](README_FA.md) | [العربية](README_AR.md) | [Español](README_ES.md) | [Русский](README_RU.md) | [Türkçe](README_TR.md) | [中文](README_ZH.md)

این پروژه بر پایهٔ [Sir-MmD/vpn-ui](https://github.com/Sir-MmD/vpn-ui) و 3X-UI است. سورس، نصب و به‌روزرسانی این نسخه از **admin6501/vpn-ui** انجام می‌شود. پس از پاک‌سازی تاریخچه، انتشارها از **v1.0.0** شروع می‌شوند و اصلاحات قبلی در سورس حفظ شده‌اند.

## امکانات

- پروتکل‌های Xray و AnyTLS، TUIC و NaiveProxy، هسته‌های قابل‌حمل، ربات تلگرام و محدودیت‌های کاربران.
- تبدیل بکاپ پاسارگارد: کاربران، ادمین و مالکیت، تخصیص اینباند، هاست‌ها و توکن‌های اشتراک حفظ می‌شوند؛ نودها وارد نمی‌شوند.
- افزودن، ویرایش و حذف نقش نماینده، نمایش کاربران هر مالک و انتقال مالکیت توسط مدیر اصلی. نقش دارای نماینده قابل حذف نیست.
- شمارش کاربران و آنلاین‌ها به‌صورت یکتا، حتی با چند اینباند؛ اصلاح فارسی فرم‌ها و زبان ربات تلگرام.
- حذف بخش دونیت و مجوز پروکسی خارجی نمایندگان.
- باینری کامل شامل هسته‌های قابل‌حمل و شش فایل geoip/geosite عمومی، ایران و روسیه است؛ بسته‌های سیستم‌عامل و ماژول‌های کرنل جدا هستند.

## پروتکل‌ها و پیش‌نیازها

VLESS، VMess، Trojan، Shadowsocks و AnyTLS/TUIC/NaiveProxy در Xray، به‌همراه OpenVPN، OpenConnect، L2TP/IPsec، PPTP، SSTP، IKEv2 و WireGuard/AmneziaWG در دسترس‌اند. پیش‌نیازهای هر هسته در صفحهٔ هسته‌ها مشخص است؛ وجود فایل اجرایی، جایگزین TUN/PPP/IPsec یا ماژول کرنل نیست. [معماری](docs/ARCHITECTURE.md) سازوکار RADIUS و ارتباط مصرف کاربران را توضیح می‌دهد.

## نصب آنلاین

باینری منتشرشده مخصوص **Linux amd64** است؛ **root و systemd** لازم است. Ubuntu 24.04 یا Debian 12/13 پیشنهاد می‌شود. تمام توزیع‌ها و پروتکل‌ها در این فورک آزمایش عملی نشده‌اند و Ubuntu 22.04 رسماً در بالادست پشتیبانی نمی‌شود.

```bash
curl -fsSL https://raw.githubusercontent.com/admin6501/vpn-ui/main/deploy.sh -o deploy.sh
sudo bash deploy.sh
```

مسیر نصب `/opt/vpn-ui` است. در پایان نام کاربری، رمز، پورت و مسیر ورود چاپ می‌شود. برای ورود، IP عمومی یا دامنهٔ سرور و مسیر کامل را استفاده کنید؛ `0.0.0.0` آدرس ورود نیست. نصب جدید به‌طور پیش‌فرض HTTP دارد؛ HTTPS را جدا تنظیم کنید. هم‌زمانی با پنل دیگر فقط در صورت نبود تداخل پورت ممکن است.

## نصب آفلاین

از [آخرین ریلیز](https://github.com/admin6501/vpn-ui/releases/latest)، فایل‌های `vpn-ui-amd64` و `install-offline.sh` را روی دستگاه دارای اینترنت دانلود و کنار هم روی سرور قرار دهید. برای بررسی صحت، `SHA256SUMS` را هم منتقل کنید:

```bash
sudo bash install-offline.sh ./vpn-ui-amd64
```

اسکریپت پنل، منوی مدیریت و سرویس را بدون دانلود نصب می‌کند. نصب تازه اطلاعات ورود تصادفی دارد؛ در به‌روزرسانی رمز و تنظیمات قبلی حفظ می‌شود. بکاپ خصوصی و بازگردانی در خطای نصب دارد. نصب همهٔ پروتکل‌ها تنها با باینری ممکن نیست: برخی به nftables، iproute2، Libreswan، DKMS یا ماژول‌های کرنل نیاز دارند. [راهنمای نصب آفلاین، پیش‌نیازها و بازیابی](docs/OFFLINE-INSTALL.md)

## مهاجرت از پاسارگارد

ابتدا پنل مقصد را نصب کنید. مقصد باید فاقد کاربر VPN و اینباند باشد. تنظیمات وب و TLS مقصد حفظ می‌شود:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/admin6501/vpn-ui/main/migration/install.sh)
```

زبان فارسی یا انگلیسی و مسیر کامل بکاپ ZIP را وارد کنید. بستهٔ مهاجرت فقط اسکریپت و کانفیگ دارد و از باینری نصب‌شده استفاده می‌کند؛ Python 3 و unzip لازم است. رمز ورود ادمین همان رمز قبلی پاسارگارد است؛ از هش نمی‌توان رمز اصلی را نمایش داد. توکن اشتراک حفظ می‌شود؛ در صورت تغییر IP یا دامنه باید آدرس پایهٔ جدید اشتراک را به کاربران بدهید.

[راهنمای کامل مهاجرت](migration/INSTALL-MIGRATION.fa.md). تبدیل نمونهٔ PostgreSQL/Timescale با ۳۱۹ کاربر، ۶ ادمین و ۳ هاست بررسی شده است؛ این بررسی به معنی تست اتصال زندهٔ تمام تنظیمات یا برابری کامل با امکانات پاسارگارد نیست.

## مدیریت، ساخت و آزمایش

برای منو `sudo vpn-ui` را اجرا کنید. پیش از ارتقا، دیتابیس، TLS و تنظیمات را بکاپ بگیرید؛ برای کپی SQLite سرویس را متوقف و فایل‌های WAL/SHM را هم حفظ کنید. حذف پنل و داده‌ها:

```bash
sudo /opt/vpn-ui/vpn-ui-amd64 --uninstall
```

ساخت از سورس به اینترنت، نسخهٔ Go در `go.mod`، ابزار C و پیش‌نیازهای ساخت هسته‌ها از جمله Docker نیاز دارد:

```bash
git clone --recurse-submodules https://github.com/admin6501/vpn-ui.git
cd vpn-ui
./build.sh
```

گزینه‌ها: `./build.sh --help`. برای باینری کامل، ساخت هسته و داده‌های جغرافیایی را حذف نکنید. [معماری](docs/ARCHITECTURE.md)، [آزمایش‌های Incus](test_unit/README.md) و [راهنمای انگلیسی](README.md). صدور و تمدید گواهی ACME به اینترنت نیاز دارد، حتی با کلاینت داخلی.
